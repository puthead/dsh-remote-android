## 2. 变更类型与必填动作

| 变更类型 | 典型内容 | 必须同步 |
|---|---|---|
| 接口变更（破坏性） | 字段改名/删除、状态机调整、错误码语义变化、端点移除 | ①`API契约.md` 递增 `X-Api-Version` ②需求 FR 表 ③设计文档接口表 ④测试用例 ⑤本表 ⑥`gatewayVersion` / App `versionCode` |
| 接口变更（兼容） | 新增可选字段、新增事件类型 | ①契约补字段 ②FR/TC 视情况 ③本表（`X-Api-Version` 不递增） |
| 需求变更 | 新增/删除/调整 FR、NFR | ①需求规格说明书 ②验收标准矩阵 ③TC 表 ④本表 |
| 架构变更 | 更换执行入口、传输方式、存储方式 | ①概要设计 §8 选型表 ②部署手册 ③测试计划环境矩阵 ④本表 |
| 依赖/工具链变更 | AGP/Gradle/Kotlin/Compose/Node/CLI 版本 | ①开发规范 §7 ②部署手册前置检查 ③本表 |
| 文档变更 | 新增文档、结构调整 | ①`docs/README.md` 索引 ②本表 |
| 缺陷修复 | `BUG-xx` | ①测试计划缺陷编号 ②本表（注明回归用例） |
| 安全变更 | 认证、限速、密钥存储、传输 | ①需求 NFR-SEC ②概要设计 §9 ③测试计划安全用例 ④本表（须写明安全评审结论） |

| v1.0（当前） | 文档基线 + 首次可用交付 | 契约冻结；网关 `dsh-remote`；Android `DshRemote`（debug APK）；安装/运维脚本 | 测试计划 Q1 ~ Q10 全部满足 |

> 规划版本仅作方向声明，不代表已排期实现；实际内容以届时新增的变更记录行与需求文档为准。
