## 3. 三步开始使用

PC（Windows）：
```powershell
# 1) 初始化：探测 DSH 路径、建运行目录、写入 API Key、生成 config.json
powershell -ExecutionPolicy Bypass -File .\scripts\setup-pc.ps1

# 2) 启动网关
powershell -ExecutionPolicy Bypass -File .\scripts\start-gateway.ps1

# 3) 生成 6 位配对码（5 分钟有效、一次性，并打印文本二维码）
powershell -ExecutionPolicy Bypass -File .\scripts\pair.ps1
```

手机：安装 `DSH-Remote-v1.0.0-release.apk` → 填服务器地址（内网 `http://<PC-IP>:8787`）
→ 填配对码 → 配对并保存 → 在首页输入任务并提交。

> 需要开机自启：**以管理员身份**运行 `scripts/install-autostart.ps1`。
> 需要不在家也能用：按 `docs/05-运维/部署手册.md` §7 配置 Tailscale（首选）/ frp+TLS / Cloudflare Tunnel，
> 手机端服务器地址改填隧道提供的 `https://` 地址。**切勿**把 8787 裸端口映射到公网。
